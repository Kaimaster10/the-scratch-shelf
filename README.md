# The Scratch Shelf

A scratch-off poster of 1,001 great books. Scratch away the foil on each book you finish to unveil its cover.

**Use it:** https://kaimaster10.github.io/the-scratch-shelf/

Your progress stays in your own browser. Use Export to keep a backup.

Based on the list in *1001 Books You Must Read Before You Die*, edited by Peter Boxall (2018 edition). This is an unofficial fan project, not affiliated with the book, its publisher, Goodreads or Open Library.

List data: [temporal-communities/1001-books](https://github.com/temporal-communities/1001-books) (CC0). Publication years: [Wikidata](https://www.wikidata.org/). Page counts and cover images: [Open Library](https://openlibrary.org/).
